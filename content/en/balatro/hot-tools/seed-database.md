Community-shared Balatro seed codes. Use these seeds to replicate challenge runs, test specific builds, or start with a lucky hand.

### How to Use a Seed

1. From the main menu, select **Run**
2. On the deck selection screen, look for the **Seed** input field
3. Enter the seed code exactly as shown (case-sensitive)
4. Start your run — you'll get the same starting cards, shop, and joker pool
