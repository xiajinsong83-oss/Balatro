Guides de build Balatro prouvés gagnants. Les combinaisons les plus régulières à travers les niveaux de mise.

### 1. Build Scaling Mult (Niveau S)

**Jokers cœurs :** Fibonacci + Blueprint + Brainstorm + Campfire

**Stratégie :** Concentrez-vous entièrement sur le Mult. Fibonacci donne +8 Mult par As/2/3/5/8 joué. Blueprint copie le joker à sa gauche. Brainstorm copie TOUS les jokers à sa gauche. Empilez ces trois pour un scaling exponentiel.

**Meilleur deck :** Deck Rouge (main supplémentaire) ou Deck Bleu (défausse supplémentaire)

### 2. Build Chips (Niveau A)

**Jokers cœurs :** Odd Todd + Even Steven + Pareidolia + Baron

**Stratégie :** Maximisez la valeur des chips. Odd Todd donne +31 chips par carte impaire. Even Steven donne +4 Mult par carte paire. Pareidolia fait de toutes les cartes des figures.

### 3. Build Re-déclenchements (Niveau A)

**Jokers cœurs :** Zany Joker + Yorick + Ride the Bus + Oops!

**Stratégie :** Faites marquer les cartes plusieurs fois. Empilez les re-déclenchements sur les cartes de haute valeur (As, Polychrome) pour des multiplicateurs de score massifs.

### 4. Build Économie (Niveau B)

**Jokers cœurs :** Golden Joker + Ride the Bus + Wealthy Joker + Trader

**Stratégie :** Ne manquez jamais d'argent. Achetez tous les objets du magasin, améliorez chaque carte. Lent mais extrêmement sûr pour les nouveaux joueurs.
