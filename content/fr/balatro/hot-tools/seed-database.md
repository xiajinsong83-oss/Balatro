Codes seed partagés par la communauté. Utilisez ces seeds pour reproduire des runs de défi, tester des builds spécifiques ou partir avec une main chanceuse.

### Comment Utiliser un Seed

1. Depuis le menu principal, sélectionnez **Run**
2. Sur l'écran de sélection de deck, trouvez le champ **Seed**
3. Entrez le code seed exactement (sensible à la casse)
4. Commencez votre run — vous obtiendrez les mêmes cartes de départ, le même magasin et le même pool de jokers

### Seeds de Défi Populaires

| Seed | Défi | Avantage de départ |
|------|------|-------------------|
| `Lucky777` | Run Highroller | $20 de départ et boost de joker rare |
| `Speedrun1` | Défi Speedrun | Mains de départ supplémentaires, prix réduits |
| `NoDiscard` | Auto-imposé | -2 défausses, +3 mains |
| `TheHouse` | Boss Rush | Blinds boss renforcés dès l'Ante 1 |
